01
মডিউল 01 · প্রাথমিক

শুরু এখানে: Tailwind CSS কী?

এই কোর্স ধরে নেয় আপনি শুধু বেসিক HTML জানেন (<div>, <h1>, <a>-এর মতো ট্যাগ)। CSS জানা লাগবে না। প্রতিটি উদাহরণের নিচে লাইভ ফলাফল আছে, আর প্লেগ্রাউন্ডে (উপরের বার) যা খুশি বদলাতে পারবেন।

CSS কী?

HTML বলে পেজে কী আছে, যেমন হেডিং বা বাটন। CSS বলে তা দেখতে কেমন: রং, আকার, ফাঁকা জায়গা ও লেআউট। সাধারণ CSS আলাদা ফাইলে থাকে এবং সিলেক্টর দিয়ে এলিমেন্ট বেছে নেয়:

Tailwind CSS কী?

Tailwind একটি ইউটিলিটি-ফার্স্ট ফ্রেমওয়ার্ক। CSS রুল লেখার বদলে আপনি অনেকগুলো ছোট তৈরি ক্লাস, যার প্রতিটি একটি কাজ করে, সরাসরি HTML এলিমেন্টে বসান। bg-pink-400 ব্যাকগ্রাউন্ড দেয়, px-6 দুই পাশে প্যাডিং দেয়, font-bold লেখা বোল্ড করে।

ফলাফল

কেন মানুষ এটি পছন্দ করে

  • ক্লাসের নাম বানাতে হয় না, ফাইলে ফাইলে ঘুরতে হয় না।
  • স্পেসিং, রং ও সাইজের একটি নির্দিষ্ট স্কেল ডিজাইন সামঞ্জস্যপূর্ণ রাখে।
  • যে ক্লাসগুলো ব্যবহার করেছেন শুধু সেগুলোই চূড়ান্ত CSS ফাইলে যায়, তাই ফাইল ছোট থাকে।
  • রেসপন্সিভ ডিজাইন ও স্টেট শুধু প্রিফিক্স: md:, hover:।
মূল কথা

HTML = কাঠামো। CSS = চেহারা। Tailwind = ছোট ছোট ক্লাসের বিশাল সংগ্রহ, যাতে সরাসরি HTML-এই স্টাইল করা যায়।

02
মডিউল 02 · প্রাথমিক

সেটআপ: CDN, CLI ও Vite

Tailwind ব্যবহারের তিনটি উপায় আছে, সহজ থেকে পেশাদার।

১. Play CDN (শেখার জন্য)

একটি স্ক্রিপ্ট ট্যাগ, কিছু ইনস্টল করতে হয় না। এই কোর্সের জন্য আদর্শ, আসল ওয়েবসাইটের জন্য নয়।

২. Tailwind CLI (ছোট সাইট)

Node.js ইনস্টল করুন (nodejs.org থেকে LTS ভার্সন)। Windows-এ ইনস্টলার চালিয়ে PowerShell খুলে পরীক্ষা করুন:

ইনপুট ফাইল বানান, watch মোডে বিল্ড চালু করুন, তারপর তৈরি হওয়া ফাইলটি HTML-এ যুক্ত করুন।

৩. Vite (আসল প্রজেক্ট)

Vite একটি দ্রুত ডেভ সার্ভার, যা React, Vue, Svelte ও সাধারণ JavaScript-এর সঙ্গে ব্যবহার হয়। Tailwind প্লাগইন হিসেবে যোগ করুন, তারপর মূল CSS ফাইলে @import "tailwindcss"; লিখুন।

পরামর্শ

Tailwind v4 আপনার টেমপ্লেট ফাইল নিজেই খুঁজে নেয়, তাই tailwind.config.js লিখতে হয় না। এটি আধুনিক ব্রাউজারের জন্য (Chrome 111+, Safari 16.4+, Firefox 128+)।

মূল ইউটিলিটি: স্পেসিং, সাইজ, টাইপ, রং

মডিউল 05 · প্রাথমিক

লেআউটের মূল কথা: ডিসপ্লে, পজিশন, ওভারফ্লো, z-index

ফ্লেক্সবক্স ও গ্রিডের আগে জানুন একটি এলিমেন্ট পেজে কীভাবে বসে। hidden এলিমেন্ট সরিয়ে দেয় (display: none), block ও inline-block ঠিক করে সে কীভাবে প্রবাহিত হবে, আর container প্রতিটি ব্রেকপয়েন্টে বাড়তে থাকা সর্বোচ্চ প্রস্থ দেয়।

container mx-auto px-4মাঝে বসানো পেজ প্রস্থ। v4-এ মাঝে আনা ও প্যাডিং নিজে দিতে হয়

z-10, z-50স্তরের ক্রম
overflow-hidden, overflow-auto, overflow-x-autoজায়গায় না ধরা অংশ কাটা বা স্ক্রল করা
aspect-video, aspect-squareপ্রস্থ ও উচ্চতার অনুপাত ধরে রাখা

ফলাফল

sticky স্ক্রল করে পেরিয়ে গেলেও এলিমেন্টকে দৃশ্যে ধরে রাখে। স্টিকি হেডারে top-0 অফসেট লাগে এবং সাধারণত z- মান লাগে, যাতে কনটেন্টের ওপরে থাকে।

পরামর্শ

কোনো সন্তান absolute হলে প্যারেন্টে relative দিন। না দিলে সন্তান পুরো পেজের সাপেক্ষে বসবে।

মডিউল 06 · প্রাথমিক

ব্যাকগ্রাউন্ড, গ্রেডিয়েন্ট, ফিল্টার

ব্যাকগ্রাউন্ড মানে শুধু সমতল রং নয়। v4-এ গ্রেডিয়েন্টের নাম দিকের ধরন অনুযায়ী: bg-linear-to-r সঙ্গে from-, via-, to- রং, এবং bg-radial ও bg-conic। ছবির জন্য bg-[url(/img/hero.jpg)]-এর মতো arbitrary মান ও bg-cover bg-center।
