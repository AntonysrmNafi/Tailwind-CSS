Module 01 · Beginner

Start Here: What is Tailwind CSS?

This course assumes you know only basic HTML (tags like <div>, <h1>, <a>). No CSS knowledge needed. Every example has a live Result under it, and you can edit anything in the Playground (top bar).

What is CSS?

HTML says what is on the page, such as a heading or a button. CSS says how it looks: color, size, spacing and layout. Plain CSS lives in a separate file and picks elements with selectors:

What is Tailwind CSS?

Tailwind is a utility first framework. Instead of writing CSS rules, you put many tiny ready made classes, each doing one job, straight on the HTML element. bg-pink-400 sets a background, px-6 adds horizontal padding, font-bold makes text bold.

Result

Why people like it

  • No inventing class names and no jumping between files.
  • A fixed design scale for spacing, colors and sizes keeps designs consistent.
  • Only the classes you use end up in the final CSS file, so it stays small.
  • Responsive design and states are just prefixes: md:, hover:.
Key takeaway

HTML = structure. CSS = looks. Tailwind = a huge set of small classes so you can style directly in your HTML.

Module 02 · Beginner

Setup: CDN, CLI and Vite

There are three ways to use Tailwind, from easiest to professional.

1. Play CDN (for learning)

One script tag, nothing to install. Perfect for this course, not meant for real websites.

2. Tailwind CLI (small sites)

Install Node.js (the LTS version from nodejs.org). On Windows, run the installer, then open PowerShell and check it worked:

Create the input file, start the build in watch mode, then link the generated file in your HTML.

3. Vite (real projects)

Vite is a fast dev server used with React, Vue, Svelte and plain JavaScript. Add Tailwind as a plugin, then put @import "tailwindcss"; in your main CSS file.

Tip

Tailwind v4 finds your template files automatically, so there is no tailwind.config.js to write. It targets modern browsers (Chrome 111+, Safari 16.4+, Firefox 128+).

Core Utilities: Spacing, Sizing, Type, Color

Utility names follow a pattern: property-value, such as p-4 or text-xl. Learn the families once and you can guess most names.

Spacing

The scale is based on 0.25rem (4px). So p-4 is 16px.

Color

Colors are color-shade: bg-sky-500, text-rose-600, border-lime-300. Shades run from 50 (lightest) to 950 (darkest). Add opacity with a slash: bg-black/50.

Result

sticky keeps an element in view after you scroll past it. A sticky header needs a top-0 offset and usually a z- value so it stays above the content.

Backgrounds, Gradients, Filters

Backgrounds go beyond a flat color. v4 names gradients by direction type: bg-linear-to-r with from-, via- and to- colors, plus bg-radial and bg-conic. Photos use an arbitrary value like bg-[url(/img/hero.jpg)] with bg-cover bg-center.

blur-sm, grayscale, brightness-125, drop-shadow-lgFilters on the element itself
mix-blend-multiplyBlend with what is underneath
Result
Caution

backdrop-blur needs something visible behind the element, and a semi transparent background such as bg-white/30, or you will see no effect.

Module 08 · Intermediate

Grid

Grid arranges items in rows and columns at once, ideal for card layouts and page sections. grid-cols-3 makes three equal columns, and col-span-2 lets an item cover two of them.

Result
ClassEffect
grid, grid-cols-2, grid-cols-12Number of columns
col-span-2, row-span-2Cover several columns or rows
gap-4, gap-x-6, gap-y-2Spacing between cells
place-items-centerCenter items inside their cells
Key takeaway

Rule of thumb: one dimension (a row of things) uses flex, two dimensions (rows and columns) use grid.

Tailwind is mobile first. A class with no prefix applies to all screens. A prefix such as md: means this width and wider. So grid-cols-1 md:grid-cols-3 is one column on phones and three from medium screens up.

Module 10 · Intermediate

States and Variants

A variant is a prefix that applies a class only in some situation. hover:bg-pink-300 works on mouse over, focus: when focused, active: while pressed, disabled: on disabled controls.

  • group: mark a parent with group, then style children with group-hover:.
  • peer: mark an earlier sibling with peer, then style the next one with peer-checked:.
  • Position variants: first:, last:, odd:, even:.
  • Dark mode: dark:bg-black follows the system setting by default.
Result

Switch dark mode yourself

To control dark mode with a button, add one line that ties dark: to a dark class on the page.

Module 11 · Intermediate

Advanced Variants and Container Queries

Tailwind v4 has variants for almost every state. A few of the most useful:

  • has-checked: styles a parent based on its child, for example a card that highlights when its radio is selected.
  • aria-pressed:, aria-expanded:, data-[state=open]: style from attributes, which fits UI libraries.
  • not-hover: applies when a state is not active.
  • placeholder:, selection:, file:, marker:, first-letter:, open: target special parts of elements.
  • starting: sets the style an element has when it first appears, to animate entry.
Result

Container queries

Media queries look at the screen. Container queries look at the parent, so a component adapts to the space it is given. Mark the parent with @container and use @sm:, @md:, @lg: on children.

Key takeaway

Use responsive prefixes for page layout and container queries for reusable components, like a card that may sit in a sidebar or a wide column.

Module 15 · Advanced

Customization: Theme, Arbitrary Values, @apply

Tailwind v4 is configured in CSS. Variables inside @theme become utilities: --color-brand gives bg-brand and text-brand, --shadow-brutal gives shadow-brutal, and --breakpoint-3xl gives a 3xl: prefix.

Result

Your own utilities and components

@utility defines a new utility class. @apply pastes utilities into your own class, handy for things you cannot template, like third party widgets.

Tip

Prefer reusing a component in your framework over piling up @apply classes. Utilities in the markup are the point of Tailwind.

Module 16 · Advanced

Configuration in Depth

Everything is configured in your CSS file. Here are the directives you will meet on real projects.

  • @layer base and @layer components add your own styles in the right place of the cascade, below utilities.
  • @source tells Tailwind to scan extra folders, such as a UI library in node_modules.
  • prefix(tw) makes every class start with tw:, avoiding clashes with existing CSS.
  • important makes utilities win over other CSS. A trailing ! does it for one class, like bg-red-500!.
  • @plugin loads official plugins: Typography (prose for article text) and Forms.
  • @custom-variant defines a variant of your own.
  • @reference lets a scoped component style (Vue, Svelte) use your theme and @apply.

A dark mode toggle button

With the @custom-variant dark line from the states module, this script adds the dark class, remembers the choice and respects the system setting on the first visit.

Caution

Resetting the palette with --color-*: initial; removes every default color. Classes such as bg-pink-400 then stop working until you define your own.

Module 17 · Advanced

Reuse and Accessibility

Long class lists look scary but are easy to manage. Repeat a pattern more than a few times? Turn it into a component in your framework (React, Vue, Svelte, or template partials). The classes then live in one place.

Accessibility checklist

  • Use real elements (button, a, label) before adding ARIA.
  • Keep a visible focus style, for example focus-visible:ring-4.
  • Check color contrast between text and background.
  • Hide text visually but keep it for screen readers with sr-only.
  • Respect motion-reduce:.
Result
Key takeaway

Good Tailwind is just good HTML plus classes. Semantic tags and focus states matter more than any class name.

Module 18 · Advanced

Frameworks, Tooling and Production

Most frameworks use Vite, so the setup from module 02 works almost everywhere. Add the @tailwindcss/vite plugin, then @import "tailwindcss"; in your main CSS.

FrameworkHow to add Tailwind v4
React, Vue, Svelte, Astro, SvelteKit, Laravel, NuxtUse the Vite plugin @tailwindcss/vite
Next.js, AngularUse @tailwindcss/postcss in the PostCSS config
Plain HTML or any backendUse the Tailwind CLI and link the output file

Tools that save time

  • The Tailwind CSS IntelliSense VS Code extension: autocomplete, hover previews and errors.
  • prettier-plugin-tailwindcss sorts class names into a consistent order.
  • clsx with tailwind-merge builds conditional class lists and resolves conflicts such as px-4 against px-6.

The classic mistake

Shipping to production

Tailwind only generates the classes it finds, so the output is small. Build a minified file and deploy that.

Tip

If a class does not work: check the spelling, check that the file is scanned (see @source), confirm the CSS file is linked, and inspect the element in DevTools to see which rule wins.
